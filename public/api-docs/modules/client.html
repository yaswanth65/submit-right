📄 Client API

Document management, payments, and messaging for clients

GET /api/client/documents

GET /api/client/documents 🔒 Auth Required

List client's documents

Retrieve all documents submitted by the authenticated client with optional filtering and sorting.

Authentication: JWT token in Authorization header
📥 Query Parameters (Optional)
  • search - Search by document title
  • status - Filter by status (draft, submitted, being_edited, completed, etc.)
  • sort - Sort order: latest (default), oldest, a_to_z
📤 Response (200 OK)
{ "success": true, "data": { "totalSubmittedDocumentsCount": 5, "documents": [ { "id": "doc-123", "document_title": "Research Paper", "status": "completed", "academic_field": "Computer Science", "document_type": "thesis", "created_at": "2026-03-15T10:30:00Z", "updated_at": "2026-04-01T14:22:00Z" } ] } }

Use Cases

1. Dashboard Display Show all client's documents in dashboard with filters
2. Document Search Search documents by title on documents page

POST /api/client/documents

POST /api/client/documents 🔒 Auth Required

Create new draft document

Create a new draft document. Document starts in draft status and can be updated before submission.

Authentication: JWT token in Authorization header
📥 Request Body
Field Type Description
documentTitle string Title of the document (max 200 chars)
academicField string Academic field (Engineering, Medicine, etc.)
documentType string Type: thesis, essay, research_paper, etc.
shortDescription string Brief description of document (max 500 chars)
{ "documentTitle": "Climate Change Impact Study", "academicField": "Environmental Science", "documentType": "research_paper", "shortDescription": "Analysis of climate change impacts on marine ecosystems" }
📤 Response (201 Created)
{ "success": true, "data": { "id": "doc-456", "document_title": "Climate Change Impact Study", "status": "draft", "academic_field": "Environmental Science", "document_type": "research_paper", "short_description": "Analysis of climate change impacts on marine ecosystems", "draft_expires_at": "2026-04-02T12:30:00Z", "created_at": "2026-04-02T10:30:00Z" } }

Error Codes

400
Invalid input - missing required fields or exceeds character limits
401
Unauthorized - invalid token

POST /api/client/documents/upload

POST /api/client/documents/upload 🔒 Auth Required

Upload document file

Upload the actual document file (.pdf, .docx, etc.) for a draft document.

Authentication: JWT token in Authorization header
📥 Request (Form Data)
  • documentId - ID of the draft document (string)
  • file - File to upload (multipart/form-data)
📤 Response (200 OK)
{ "success": true, "data": { "id": "doc-456", "uploaded_file_name": "document.pdf", "uploaded_file_url": "https://storage.example.com/docs/doc-456.pdf", "uploaded_file_path": "client-123/doc-456/client/1712040900000-document.pdf", "word_count": 2450, "last_activity_at": "2026-04-02T10:35:00Z" } }

Use Cases

1. Document Upload Client uploads document file during submission process

Error Codes

400
Missing documentId or file
404
Document not found
413
File too large

GET/POST /api/client/messages

POST /api/client/messages 🔒 Auth Required

Send message to editor

Send a message to the assigned editor for a document.

📤 GET Response (200 OK)
{ "success": true, "data": [ { "id": "doc-456", "document_title": "Climate Change Impact Study", "assigned_editor_id": "editor-456", "status": "being_edited", "profiles": { "id": "editor-456", "full_name": "Jane Editor", "email": "jane@example.com" } } ] }
Authentication: JWT token in Authorization header
📥 Request Body
Field Type Description
documentId string Document ID for messaging context
receiverId string Recipient profile ID (editor)
message string Message content (1-5000 chars)
{ "documentId": "doc-456", "receiverId": "editor-456", "message": "Can you focus on improving clarity in the introduction?" }
📤 Response (201 Created)
{ "success": true, "data": { "id": "msg-789", "document_id": "doc-456", "sender_id": "client-123", "receiver_id": "editor-456", "message": "Can you focus on improving clarity...", "created_at": "2026-04-02T11:00:00Z" } }

Error Codes

400
Invalid documentId or message too long
404
Document not found or no editor assigned
