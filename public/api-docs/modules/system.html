⚙️ System API

Platform maintenance and automated cleanup operations

POST /api/system/cleanup-drafts

POST /api/system/cleanup-drafts ⏰ Cron Job

Clean up expired draft documents

Automated maintenance endpoint that deletes draft documents that have expired. Should be called periodically via cron job or scheduled task.

⚠️ Note: This is a system maintenance endpoint designed to run automatically via cron jobs or scheduled tasks, not for direct API calls. No authentication required (assumes internal network access).
📤 Response (200 OK)
{ "deletedCount": 12, "deletedDrafts": [ { "id": "doc-draft-001", "document_title": "Old Draft Paper", "expired_at": "2026-03-29T10:30:00Z" }, { "id": "doc-draft-002", "document_title": "Unused Document", "expired_at": "2026-03-28T15:45:00Z" } ], "executed_at": "2026-04-02T00:00:00Z" }

How It Works

  1. Query database for draft documents with status = 'draft'
  2. Find drafts where draft_expires_at < current_time
  3. Delete matching draft documents from the database
  4. Clean up associated files from storage (if applicable)
  5. Return count of deleted drafts and list of deleted items
  6. Log cleanup operation for audit trail

Draft Expiration Policy

  • Draft Creation: New drafts are created with draft_expires_at timestamp
  • Expiration Period: Drafts expire after 30 days of inactivity (configurable)
  • Auto-Cleanup: Expired drafts are permanently deleted
  • Grace Period: Clients may receive warning notification 7 days before expiration

Database Impact

  • Deletes records from documents table where status = 'draft' and expired
  • Deletes associated document_services entries
  • Cleans up attached files from storage location
  • Creates audit log entry for deletion

Scheduling Recommendations

This endpoint should be executed regularly:

  • Frequency: Daily (recommended at off-peak hours)
  • Time: 2:00 AM (02:00) server time
  • Cron Expression: 0 2 * * * (Daily at 2 AM)
⏰ Cron Job Example:
# Run cleanup daily at 2 AM 0 2 * * * curl -X POST https://api.submitright.com/api/system/cleanup-drafts?secret=YOUR_CRON_SECRET # Or using a task scheduler (Windows) schtasks /create /tn "CleanupDrafts" /tr "curl -X POST http://api.submitright.com/api/system/cleanup-drafts" /sc DAILY /st 02:00

Security Considerations

  • This endpoint should only be accessible from internal networks or cron job runners
  • Consider requiring a secret token parameter for additional security
  • Monitor execution logs for failures or anomalies
  • Set up alerts if cleanup fails to complete

Performance Considerations

  • Large-scale deletions (1000+ drafts) may take several minutes
  • Consider running during low-traffic periods to minimize impact
  • Monitor database performance during execution
  • Can be batched if needed for very large datasets

Error Handling

  • Partial failures are logged separately
  • Failed file deletions don't prevent database cleanup
  • Execution continues even if some drafts fail to delete
  • Returns count of successfully deleted items

Monitoring

Track the following metrics:

  • Number of drafts deleted per execution
  • Storage space freed (if tracked)
  • Execution duration
  • Error rate and failure reasons
  • Database load during cleanup
