✏️ Editor API

Document editing, submission, notifications, and availability management

GET /api/editor/dashboard

GET /api/editor/dashboard 🔒 Auth Required

Get editor dashboard summary

Retrieve dashboard statistics including active documents, pending revisions, and due dates.

Authentication: JWT token in Authorization header
📤 Response (200 OK)
{ "activeDocumentCount": 3, "activeDocuments": [...], "pendingRevisionCount": 1, "pendingRevisionDocuments": [...], "dueTodayCount": 1, "dueTodayDocuments": [...], "completedCount": 12, "completedDocuments": [...], "recentActivity": [...], "dueSoon": [...], "user": { "full_name": "Jane Editor", "email": "jane@example.com" } }

Use Cases

1. Dashboard Display Show editor their work summary and statistics
2. Priority Management Display documents due today or soon

GET /api/editor/documents 🔒 Auth Required

List assigned documents

GET /api/editor/documents/[id]

GET /api/editor/documents/[id] 🔒 Auth Required

Get document details

Retrieve full details of a specific document assigned to the editor.

Authentication: JWT token in Authorization header
📥 Path Parameters
  • id - Document ID (string)
📤 Response (200 OK)
{ "id": "doc-123", "document_title": "Research Paper", "status": "being_edited", "academic_field": "Computer Science", "document_type": "thesis", "file_url": "https://storage.example.com/doc-123.pdf", "deadline_at": "2026-04-10T23:59:59Z", "client": { "id": "client-456", "full_name": "John Client", "email": "john@example.com" } }

Error Codes

404
Document not found or not assigned to editor

POST /api/editor/documents/submit

POST /api/editor/documents/submit 🔒 Auth Required

Submit edited document

Upload edited document file and submit it back to the client.

Authentication: JWT token in Authorization header
📥 Request (Form Data)
  • documentId - Document ID being submitted (string)
  • file - Edited document file (multipart/form-data)
📤 Response (200 OK)
{ "id": "doc-123", "status": "submitted_by_editor", "submitted_at": "2026-04-02T15:30:00Z", "edited_file_url": "https://storage.example.com/doc-123-edited.pdf" }

Error Codes

400
Missing documentId or file
404
Document not found

POST /api/editor/documents/request-extension

POST /api/editor/documents/request-extension 🔒 Auth Required

Request deadline extension

Request additional time to complete document editing.

Authentication: JWT token in Authorization header
📥 Request Body
Field Type Description
documentId string Document ID
extensionDays number Number of days to extend (1-7)
reason string Reason for extension (max 500 chars)
{ "documentId": "doc-123", "extensionDays": 2, "reason": "Complex document requires additional review time" }
📤 Response (200 OK)
{ "documentId": "doc-123", "extensionRequested": true, "newDeadline": "2026-04-12T23:59:59Z", "requestedAt": "2026-04-02T14:00:00Z" }

Error Codes

400
Invalid extension days (must be 1-7)

POST /api/editor/messages

POST /api/editor/messages 🔒 Auth Required

Send message to client

Send a message to the client regarding a document.

Authentication: JWT token in Authorization header
📥 Request Body
Field Type Description
documentId string Document ID for messaging context
message string Message content (max 2000 chars)
{ "documentId": "doc-123", "message": "I've completed the initial review. Please check for my suggestions." }
📤 Response (201 Created)
{ "id": "msg-123", "documentId": "doc-123", "senderId": "editor-456", "receiverId": "client-789", "message": "I've completed the initial review...", "createdAt": "2026-04-02T14:30:00Z" }

GET /api/editor/availability

GET /api/editor/availability 🔒 Auth Required

Get editor availability

Retrieve the editor's current availability status and limits.

Authentication: JWT token in Authorization header
📤 Response (200 OK)
{ "editor_id": "editor-456", "availability_status": "available", "maximum_active_assignments": 5, "maximum_word_count_per_day": 5000, "vacation_start_date": null, "vacation_end_date": null, "updated_at": "2026-04-01T10:00:00Z" }
PATCH /api/editor/availability 🔒 Auth Required

Update availability settings

📥 Request Body (All Optional)
Field Type Description
availabilityStatus string Status: available, busy, at_capacity, vacation
maximumActiveAssignments number Max concurrent assignments (1-20)
maximumWordCountPerDay number|null Max words per day, null for unlimited
vacationStartDate string|null ISO 8601 date format
vacationEndDate string|null ISO 8601 date format
{ "availabilityStatus": "vacation", "vacationStartDate": "2026-04-15", "vacationEndDate": "2026-04-20" }
📤 Response (200 OK)
{ "editor_id": "editor-456", "availability_status": "vacation", "maximum_active_assignments": 5, "vacation_start_date": "2026-04-15", "vacation_end_date": "2026-04-20", "updated_at": "2026-04-02T11:00:00Z" }

POST /api/editor/delete-account

POST /api/editor/delete-account 🔒 Auth Required

Delete editor account

Permanently delete the editor's account and all associated data.

Authentication: JWT token in Authorization header
📥 Request Body
Field Type Description
password string Password for confirmation
reason string|null Reason for deletion
{ "password": "EditorPassword123", "reason": "No longer interested in editorial work" }
📤 Response (200 OK)
{ "success": true, "message": "Account deleted successfully", "email": "jane@example.com" }

Error Codes

400
Missing password or has active assignments
401
Invalid password
