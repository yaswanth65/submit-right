POST /api/admin/clients/restrict

POST /api/admin/clients/restrict 🔒 Auth Required

Restrict client account

Restrict a client account preventing them from submitting new documents.

Authentication: Admin JWT token required
📥 Request Body
Field Type Description
targetUserId string Client ID to restrict
reason string Reason for restriction (max 500 chars)
{ "targetUserId": "client-123", "reason": "Repeated policy violations" }
📤 Response (201 Created)
{ "success": true, "auditLogId": "audit-123", "action": "restrict_client_account", "targetUserId": "client-123" }

POST /api/admin/clients/suspend

POST /api/admin/clients/suspend 🔒 Auth Required

Suspend client account

Temporarily suspend a client account.

Authentication: Admin JWT token required
📥 Request Body
Field Type Description
targetUserId string Client ID to suspend
reason string Reason for suspension (max 500 chars)
suspensionDays number|null Duration in days (null = indefinite)
📤 Response (201 Created)
{ "success": true, "action": "suspend_client_account", "targetUserId": "client-123", "suspensionUntil": "2026-04-10T00:00:00Z" }

POST /api/admin/documents/assign

POST /api/admin/documents/assign 🔒 Auth Required

Assign document to editor

Assign a submitted document to an editor for editing.

Authentication: Admin JWT token required
📥 Request Body
Field Type Description
documentId string Document ID
editorId string Editor ID to assign to
reason string Assignment notes (max 500 chars)
{ "documentId": "doc-123", "editorId": "editor-456", "reason": "Editor specializes in academic research papers" }
📤 Response (200 OK)
{ "id": "doc-123", "assigned_editor_id": "editor-456", "status": "being_edited", "assigned_at": "2026-04-02T12:30:00Z" }

PATCH /api/admin/documents/deadline

PATCH /api/admin/documents/deadline 🔒 Auth Required

Adjust document deadline

Modify the deadline for a document under editing.

Authentication: Admin JWT token required

Field Type Description

📤 Response (200 OK)
{ "id": "doc-123", "deadline_at": "2026-04-15T23:59:59Z", "updated_at": "2026-04-02T13:00:00Z" }
